# Transition Builder: архитектурный контракт

Редактор, Preview и экспорт используют один документ `TransitionProject` и общий движок отображения. Координаты объектов всегда хранятся относительно логической сцены 1920 × 1080.

Локальные ресурсы хранятся отдельно от слоёв и подключаются через `assetId`. Это не позволяет повторяющимся изображениям создавать несколько копий Base64. Автономные HTML и JSON встраивают локальные ресурсы только на этапе экспорта.

Формат проекта версионируется через `schemaVersion`. Изменения схемы должны сопровождаться миграцией.
